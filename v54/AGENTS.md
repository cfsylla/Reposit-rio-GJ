# Grand Journey conventions

- Implement and publish updates only when the user explicitly authorizes an update. Treat bug reports and future ideas as pending otherwise.
- Card browsing menus use three columns at all supported mobile widths, including Card Cycle piles, collection, custom deck and training. Do not add mobile rules that reduce them to two columns. Keep gameplay-specific arrangements such as the four-card hand and formation grid unchanged.
- Fixed-screen identity rule: the whole page/game screen must NEVER scroll, at any round or supported viewport. Only bounded menus/panels inside the fixed screen may scroll. Primary actions (Continue, Fight, Confirm, Back, etc.) must always remain visible and reachable without scrolling, in a separate fixed layout row outside all scrolling content. Reduce redundant information and fit the layout before allowing overflow; never solve overflow by adding scrolling to the whole arena/screen. Apply to every new screen and every changed screen. Validate the longest content, raid round 3 and later, and supported mobile sizes before delivery.
- Bottom action bars must have an opaque background extending to the lower edge and safe area. No cards or other content may show behind or below them. Prefer the shared screen-footer row outside screen-scroll. Keep the last content row fully reachable by scrolling. Apply this to new menus too.
- Typography: preserve the original Georgia Grand Journey wordmark and Nunito tagline. Validated interface font is locally bundled VT323 Regular 400, including buttons and canvas. Preserve its native weight to match the approved comparison. Preview alternatives before any future global replacement. Preserve Portuguese accents and bundled font licenses.
- Preserve saved game compatibility, hidden Blackfang unlock rules and existing Site access unless the user requests changes.
